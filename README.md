# literate-sniffle
Firewall Blocker – a lightweight Windows tool to block internet access for any app. Add a folder, select a protocol (TCP, UDP, ICMP, etc.), and block all .exe files inside recursively. Ideal for stopping license checks, auto-updates, and telemetry in SOLIDWORKS &amp; CATIA. Portable, no install, one-click restore. Built with C++ Win32 API – no .NET.
